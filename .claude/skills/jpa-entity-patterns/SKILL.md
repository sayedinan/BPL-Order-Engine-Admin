# JPA entity patterns (v0.3)

v0.3 introduces JPA entities (`User`, `Engine`, `AuditLog`) to replace
v0.2's in-memory mocks. This file pins the conventions; deviations are
flagged by `qa-reviewer.md`.

> **Note on naming:** The field `User.assignedEngines` is the JPA code
> name. In user-facing docs and the SPEC, per-engine grants are
> sometimes called "roles" (because the PRD used that word, and each
> role name is conventionally the engine code, e.g. role `BPL` =
> access to engine `BPL`). The two terms refer to the same thing. The
> data shape is a join table; the field is `assignedEngines`.

## Universal rules (every entity)

1. **UUID primary key.** `@Id @Column(columnDefinition = "uuid") private UUID id;` Generated by the application (`UUID.randomUUID()` in a `@PrePersist`), not by the DB. This makes ids stable across DB migrations and easier to reference in audit logs and API responses.
2. **`@Version` for optimistic locking.** `private long version;` Required on `User`, `Engine`, and `AuditLog`. Hibernate increments on every UPDATE; a `OptimisticLockException` on a concurrent edit → retry the transaction (or surface 409 if the retry fails).
3. **No Lombok `@Data` on entities.** Use `@Getter` `@Setter` (and `@ToString` with `exclude = {...}` for the to-many fields). `@Data` generates `equals`/`hashCode` over every field, which combined with Hibernate's lazy-loading proxies causes `LazyInitializationException` and infinite recursion in bidirectional relationships.
4. **Equals and hashCode by `id` only.** If `id == null` (transient, not yet persisted), use reference equality (`return this == other;`). Don't use `Objects.hash(id)` if `id` can be null — two transient entities with the same field values would be `equal`, which is wrong.
5. **`FetchType.LAZY` on every to-many.** `User.assignedEngines` is `Set<Engine>` with `FetchType.LAZY`. The dashboard query explicitly fetches the join with `JOIN FETCH` when it needs the engine codes. Same for any future `OneToMany`.
6. **`@JsonIgnore` on the JPA side of the cycle.** The DTO is the API contract; the entity is the persistence model. If a `User` JSON response would otherwise include every assigned `Engine`'s every assigned `User`, you've crossed the line.
7. **Validation annotations from `jakarta.validation`**, not Spring's custom ones. `@NotBlank`, `@Size`, `@Pattern`, `@Email`. Activated by `@Valid` on the controller method's `@RequestBody` parameter. Requires `spring-boot-starter-validation` (not in v0.2; add it now).
8. **Timestamps via `@PrePersist` / `@PreUpdate`.** `createdAt` (immutable), `updatedAt` (mutable). On `AuditLog`, only `timestamp` (immutable, set on insert).

## The three entities

### `User`

```java
@Entity
@Table(name = "users", uniqueConstraints = @UniqueConstraint(columnNames = "username"))
@Getter @Setter
public class User {

    @Id
    @Column(columnDefinition = "uuid")
    private UUID id;

    @Version private long version;

    @Column(nullable = false, length = 64)
    private String username;

    @Column(nullable = false, length = 100)
    private String passwordHash;          // BCrypt; never @Encrypted, the hash is already one-way

    @Column(nullable = false, length = 100)
    private String email;                 // for the change-password / forgot flow later; nullable for v0.3

    @Enumerated(EnumType.STRING)
    @Column(nullable = false, length = 16)
    private RoleType roleType;             // SYS_ADMIN, ADMIN, USER

    @Column(nullable = false)
    private boolean mustChangePassword;    // true on create, false after first successful change

    @ManyToMany(fetch = FetchType.LAZY)
    @JoinTable(
        name = "user_engine_access",
        joinColumns = @JoinColumn(name = "user_id"),
        inverseJoinColumns = @JoinColumn(name = "engine_id")
    )
    @Builder.Default
    private Set<Engine> assignedEngines = new HashSet<>();

    @Column(nullable = false, updatable = false)
    private Instant createdAt;

    @Column(nullable = false)
    private Instant updatedAt;

    @PrePersist void onCreate() {
        if (id == null) id = UUID.randomUUID();
        Instant now = Instant.now();
        createdAt = now;
        updatedAt = now;
        if (!mustChangePasswordExplicit) mustChangePassword = true;
    }

    @PreUpdate void onUpdate() { updatedAt = Instant.now(); }
}
```

> **Field name `assignedEngines` (not `assignedRoles`).** The PRD and
> the rbac-redesign-spec sketch call per-engine grants "roles" because
> the role *name* is the engine code. In code, the field is
> `assignedEngines` because that's what it is. See the file header
> note for the alias.

`Engine.assignedUsers` is the inverse side, marked `mappedBy = "assignedEngines"`. Always access from the `User` side to avoid weird fetch behavior.

### `Engine`

```java
@Entity
@Table(name = "engines", uniqueConstraints = @UniqueConstraint(columnNames = "code"))
@Getter @Setter
public class Engine {

    @Id
    @Column(columnDefinition = "uuid")
    private UUID id;

    @Version private long version;

    @Column(nullable = false, length = 80)
    private String name;

    @Column(nullable = false, length = 16)
    @Pattern(regexp = "^[A-Z0-9_]{2,16}$")
    private String code;                            // BPL, PCL, etc.

    @Column(nullable = false, length = 64)
    private String serverIp;

    @Column(nullable = false, length = 64)
    private String serverUsername;

    @Encrypted                                                    // Jasypt
    @Column(nullable = false, length = 512)
    private String serverPassword;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false, length = 16)
    private EngineMode mode;                          // MOCK, REAL

    @Column(length = 1024)
    private String startScript;                        // nullable when mode = MOCK

    @Column(length = 1024)
    private String stopScript;

    @Column(length = 1024)
    private String logScript;

    @Enumerated(EnumType.STRING)
    @Column(nullable = false, length = 16)
    private EngineStatus status;                        // RUNNING, STOPPED, ERROR

    @Column
    private Instant deletedAt;                         // soft-delete; query layer filters

    // ... timestamps + @PrePersist / @PreUpdate
}
```

**`@Encrypted`** is a custom annotation. The `StringEncryptor` Jasypt bean encrypts on write and decrypts on read. The `serverPassword` is the only encrypted column; the `passwordHash` on `User` is BCrypt and stays a one-way hash.

### `AuditLog`

```java
@Entity
@Table(name = "audit_log", indexes = {
    @Index(name = "idx_audit_timestamp", columnList = "timestamp"),
    @Index(name = "idx_audit_actor", columnList = "actorUsername"),
    @Index(name = "idx_audit_engine", columnList = "targetEngineCode")
})
@Getter @Setter
public class AuditLog {

    @Id
    @Column(columnDefinition = "uuid")
    private UUID id;

    // NO @Version — audit rows are insert-only

    @Column(nullable = false, updatable = false)
    private Instant timestamp;

    @Column(nullable = false, length = 64)
    private String actorUsername;

    @Column(nullable = false, length = 16)
    private String actorRole;                          // string, not enum — historical rows can survive enum changes

    @Enumerated(EnumType.STRING)
    @Column(nullable = false, length = 32)
    private AuditAction action;

    @Column(length = 16)
    private String targetEngineCode;                   // nullable for non-engine actions

    @Column(columnDefinition = "jsonb")
    @JdbcTypeCode(SqlTypes.JSON)                       // Hibernate 6 JSON support; PostgreSQL jsonb
    private String details;                             // serialized JSON, capped 2KB

    @PrePersist void onCreate() {
        if (id == null) id = UUID.randomUUID();
        if (timestamp == null) timestamp = Instant.now();
    }
}
```

Audit rows are **insert-only** — no `@Version`, no `updatedAt`, no setters that allow mutation after persist (defensive: the setters exist for Hibernate, but the service layer never calls them after save).

## Migrations (Flyway)

- `src/main/resources/db/migration/V1__init.sql` creates the tables. Use `uuid` type (Postgres native) for PKs and FKs.
- `V2__seed_admin.sql` (dev profile only, via `spring.flyway.locations` or a separate `db/seed/` directory gated by profile) inserts the initial `SYS_ADMIN` user with a known BCrypt-hashed password. The plaintext password is in `application-dev.properties` as a comment, NOT in the SQL.
- Don't use `spring.jpa.hibernate.ddl-auto=update` in any profile. Flyway is the source of truth; the schema lives in `db/migration/`.

## Anti-patterns

- **Don't use `Long` IDs.** UUIDs only. Long IDs leak row counts; UUIDs don't.
- **Don't use `@Data` on entities.** Ever. `qa-reviewer.md` flags this.
- **Don't use `FetchType.EAGER` on to-many associations.** Every common query path will load the world.
- **Don't use `@OneToMany` with `cascade = CascadeType.ALL`** unless you've thought very hard about what happens on entity removal. The User↔Engine association is `@ManyToMany` with explicit `@JoinTable` — no cascade, the application manages the join table.
- **Don't use `Optional` fields for nullable columns.** Just leave the field `null`. `Optional` is for return types, not for entity fields.
- **Don't use field-level `@Convert` for the audit `details` JSON.** Use `@JdbcTypeCode(SqlTypes.JSON)` from Hibernate 6; it handles the round trip via Jackson and stores in `jsonb` on Postgres.
- **Don't put the JPA entity in the API response.** Always map to a DTO. The DTO is the contract; the entity is the persistence model.
- **Don't use the term `assignedRoles` in code.** It's `assignedEngines`. The PRD uses "role" as a synonym; the code does not.
